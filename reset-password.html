Reimposta password

Per gli utenti registrati nel progetto Supabase di 7K Racing. Nessuna password viene salvata in questa pagina.

Questa pagina è aperta come file sul computer. Per ricevere e utilizzare correttamente il link di recupero, pubblica reset-password.html nel repository GitHub Pages del sito e aprila dal suo indirizzo HTTPS.

1. Ricevi il link via email

Apri l'email ricevuta e clicca sul link: tornerai a questa pagina per scegliere una nuova password.

2. Scegli la nuova password

Link di recupero riconosciuto. Inserisci una password di almeno 10 caratteri.

Configurazione Supabase (solo prima volta)

Inserisci il Project URL e la chiave pubblica del tuo progetto. Questi due valori vengono conservati soltanto nel browser corrente.

NON inserire chiavi secret o service_role. Non inserire qui la password dell'account.

Attivazione sul sito

Carica questo file con il nome reset-password.html nella cartella principale del repository GitHub 7k-betakomoinen.

In Supabase → Authentication → URL Configuration → Redirect URLs aggiungi:

https://alzimer24-sudo.github.io/7k-betakomoinen/reset-password.html

Poi apri esattamente quell'indirizzo dal browser e configura i due valori pubblici. Il file originale index.html non viene modificato.
